# Vezha — збірки для оновлення / builds for updates

Тут лише готові APK застосунку Vezha (IPTV-плеєр для Android, Android TV і ТВ-приставок) — з них версія з GitHub
сама перевіряє й завантажує оновлення («Налаштування → Про Vezha»). Релізи публікує CI автоматично; вихідний код —
в окремому приватному репозиторії.

Only ready-made Vezha APKs live here (IPTV player for Android, Android TV and TV boxes) — the GitHub version of the app
checks and downloads updates from these releases ("Settings → About Vezha"). Releases are published by CI; the source
code is in a separate private repository.
